为什么会有GuideBloom?

1、GuideBloom是什么？
GuideBloom的起源是我准备英语导游证考试的过程中，发现市面上大多数的app都要付费，于是决定自己做一个工具来帮助自己学习。是的，通俗的来说，它就是一个应试刷题工具。

2、它为什么存在？
我相信我刚刚也已经回答了这个问题。它的存在，不仅是我想自己想要考证，但是支付不起付费学习软件的钱，还是我想通过这个方式在解决我本身的需求中，探索这个项目的开发，帮助自己落地自己的想法，并且能帮助到跟我用相同处境的人。

3、它希望陪伴什么样的人？
从目前来看，我希望它能很好的陪伴我，能满足我的基本需求，哪怕它不完美，但是它是属于我的，我可以慢慢改进。如果我的作品有人能看到并觉得有用，甚至还愿意给我建议，我会非常感激，从此我就会希望它陪伴的人很多，包括有自己严谨备考计划的人，也包括临近考试了还一筹莫展的人，还包括想要随时随利用碎片化时间刷题的人……总之，我想尽可能地帮助更多有刷题需求的人，因为在未来我也有可能处于我刚刚说到的任何一种处境。

当前目标：帮助我学习导游证

未来规划：不断完善它，让它成为我的个人作品
